# 栖边本机同步服务

适用于同一台 Windows 10/11 x64 电脑上的 Edge、Chrome。两个浏览器都必须安装栖边 1.5.0 或更新版本。其他 Chromium 浏览器可能兼容，但本次不声明已验证。没有发布 macOS、Linux、Windows ARM64 或 32 位运行包。

1. 把完整便携包解压到固定目录，例如“文档”下的“栖边同步”；不要在 ZIP 预览里运行。已经包含官方 Node.js 24.22.0 x64 运行时，无需安装 Node.js、npm 或编译工具。
2. 双击 `start.cmd`，保持窗口运行。服务只监听 `127.0.0.1:17381`，不会连接云端。
3. 复制窗口里的配对密钥。在主浏览器的栖边设置 → 跨浏览器同步中填写密钥，点击连接；等显示已连接后，再连接另一个浏览器。
4. 卡片、外观、便笺、歌单、顺序与导入的文件自动同步。音乐播放位置会显示浏览器名称，在其他浏览器可以暂停、停止或切歌。「在此浏览器播放」会先停止旧播放器，再切换播放位置。

需要开机自动运行时，右键 `install-autostart.ps1` → 使用 PowerShell 运行；会设置当前用户登录启动，并隐藏后台窗口。先关闭手动启动的服务窗口。取消自动启动运行 `remove-autostart.ps1`。安装与卸载启动项都不会删除数据。

停止手动服务可在窗口按 `Ctrl+C`。取消自动启动后，当前后台服务会在退出 Windows 时停止；也可在任务管理器中按包目录定位随包的 `node.exe` 后结束对应进程。不要结束其他程序的 Node 进程。卸载时先停止服务、取消自动启动，再删除解压目录；需要保留或备份的数据位于下述独立目录。

升级时先停止旧服务，将新包解压到新目录并启动。数据不写入程序目录；原数据和配对密钥会保留。如原来启用自动启动，在新目录再次运行 `install-autostart.ps1` 更新当前用户的启动路径。程序目录不要移动后仍保留旧启动项。

数据和密钥保存在 `%LOCALAPPDATA%\QibianSync`。备份时先退出服务再复制整个目录。文件没有大小上限，首次同步大文件需要时间；每个浏览器会保存自己的文件副本，服务另外保留一份。删除卡片会同步，服务保留文件备份，不自动清理，避免离线浏览器丢失引用。不要公开配对密钥。

首次连接采用主浏览器的全局设置，追加另一个浏览器的卡片；相同 ID 的不同内容保留副本。首次配对前的配置另存于扩展本地 `syncBackup`。断线后修改在本地排队，连接后补发；同一卡片同一字段的并发修改按服务收到的顺序确定最终内容。歌曲列表作为一个字段同步，请避免断网期间在两个浏览器同时编辑同一个歌单。

服务断开时共享播放停止。浏览器异常退出后最多等待约 12 秒才能切换播放器；这段时间用于保证旧播放器已经停止。服务重启后不会自动开始播放。

只同步已加入栖边的数据，不扫描浏览器个人资料、系统下载目录、未选择的本机文件，不控制网站自身音视频。此版本不支持跨电脑联网同步。

同步服务本身只使用回环地址，正常同步无需外网；网站、天气和信息流等扩展模块仍依赖对应网站网络。服务窗口提示“已在运行”时，请使用已有服务与 `%LOCALAPPDATA%\QibianSync\pairing-key.txt` 中的密钥；不要尝试同时启动第二个实例。
