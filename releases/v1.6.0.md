# 栖边 1.6.0

- 网页图标栏新增 ⠿ 拖动把手，支持上下移动和左右停靠，刷新后保留位置；完整网页面板跟随停靠侧。
- 设置新增停靠侧、垂直位置及恢复默认按钮。支持方向键微调，长图标列表与小窗口内保持可见，快捷组件跟随停靠侧并避免超出窗口。
- 新增「快捷方式」卡片，可手动粘贴 OneTab 等扩展页面地址，也可在授予可选标签页权限后读取当前页面或已打开的 OneTab。支持文字及上传图标，完整卡片与小图标均能直接打开；有权限时复用已有相同地址标签页。
- 快捷方式支持安全的 HTTP(S) 链接、Chrome/Edge 扩展页面及收藏夹、下载等允许的浏览器页面。普通网站卡片保持原有 HTTP(S) 地址限制。
- 位置和快捷方式加入配置备份及跨浏览器同步；同步协议增加兼容保护，所有浏览器和服务需一起更新到 1.6.0 或更新版本，旧协议不会接收并清除新数据。

## 使用

**推荐下载：[qibian-1.6.0-windows-x64.zip](https://github.com/1644ye/qibian/releases/download/v1.6.0/qibian-1.6.0-windows-x64.zip)**，包含扩展、本机同步服务、运行时和使用说明，面向 Windows x64。

| 附件 | 用途 |
| --- | --- |
| qibian-1.6.0-windows-x64.zip | 推荐完整包，Windows x64 |
| qibian-extension-1.6.0.zip | 仅扩展，已验证 Windows x64 Edge / Chrome；无需同步时可选 |
| qibian-sync-1.6.0-windows-x64-portable.zip | 单独的 Windows x64 本机同步服务，自带 Node.js 运行时 |
| SHA256SUMS.txt | 三个成品包的 SHA-256 校验值 |

1. 完整解压到固定文件夹，打开 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions`。
2. 开启该页面的「开发人员模式」，点击「加载解压缩的扩展」，选择包内 `extension` 文件夹；单独扩展包选择解压后的根目录。无需安装开发环境或编译。
3. 刷新普通网页，拖动图标栏顶部 ⠿ 调整位置。添加内容 → 快捷方式 → 读取已打开的 OneTab，或粘贴扩展页面地址后保存。

升级继续使用原加载目录并重新加载，不卸载旧扩展。OneTab 等目标扩展需已在当前浏览器安装启用；快捷方式打开其页面，不触发收集全部标签的按钮操作。GitHub 自动生成的 Source code 压缩包是源码，不是成品。

使用跨浏览器同步时，退出旧服务，更新所有浏览器扩展并启动包内 `sync/start.cmd`。运行时随包提供；原有配对密钥和数据保留在 `%LOCALAPPDATA%\QibianSync`。

扩展卡片和文件保存在各浏览器的扩展存储及 IndexedDB。升级前导出配置并保存歌曲和文件原件；JSON 配置备份不含文件本体。本机同步服务的数据可在退出服务后整体复制备份。天气、RSS 和网站图标读取需要联网，无需 API Key；已保存的便笺、文件和音乐可离线使用。

## 验证与范围

本机 Windows x64 上已执行 54 项单元测试；真实 Edge 成品验证 7 组位置与快捷方式测试、原有 13 组卡片/导入/备份回归，以及原生边栏空间恢复与后台音乐测试。真实 Edge/Chrome 9 组同步验证包含新位置/快捷方式字段、文件、歌单、远程停止/接管播放及断线恢复。

扩展快捷方式通过本地模拟 OneTab 扩展页面验证，未访问用户真实 OneTab 数据。分别验证了不授权时手动添加和已授权时读取/复用；权限确认弹窗未自动化点击。其他系统和浏览器未验证。

移动的是网页中的图标栏和网页面板；浏览器原生侧栏位置由 Edge/Chrome 管理。浏览器内部页、扩展商店等不能注入网页图标栏；部分网站拒绝内嵌或图标读取。同一个扩展在不同浏览器的 ID 或页面地址可能不同，需要分别重新读取。同步限同机栖边内的数据和播放器，不控制其他网站播放器。

未验证真实系统权限弹窗、组织策略、登录启动注册表操作、所有第三方网络服务及其他平台/架构。项目启动脚本未签名，随包官方 Node.js 的签名不等于项目签名；项目自身尚未指定开源许可证，第三方许可证与说明随包保留。
