# 栖边 1.6.1

修复原生侧栏打开不久后关闭的问题，并为 Windows 完整包增加自动更新。

- 启动初始化不再禁用用户已经打开的原生侧栏。打开侧栏统一使用窗口级实例，避免同时创建标签页级实例；收起兼容路径也不再给当前标签留下禁用覆盖。
- 扩展每 6 小时检查 GitHub 正式版本，设置新增「版本与自动更新」，支持立即检查、打开下载页和重新加载。
- 完整包的 `sync/start.cmd` 在启动时自动检查、下载并安装新版，一天最多一次成功检查；`sync/update.cmd` 可立即检查并安装。安装覆盖原程序目录，配置、歌单、文件及配对密钥保留。下载失败、断网或安装失败继续使用当前版，原程序备份保存在数据目录 `updates`。
- 更新不会主动关闭使用中的侧栏或中断音乐。所有栖边界面关闭且音乐暂停后，扩展在 5 分钟内自动重新加载；也可手动重新加载或重启浏览器。

## 下载和首次使用

**[推荐下载：qibian-1.6.1-windows-x64.zip](https://github.com/1644ye/qibian/releases/download/v1.6.1/qibian-1.6.1-windows-x64.zip)**，包含扩展、自带运行时的同步服务、更新程序及说明。另有 `qibian-extension-1.6.1.zip`（仅扩展）、`qibian-sync-1.6.1-windows-x64-portable.zip`（仅服务）和 `SHA256SUMS.txt`（三个成品包校验值）。仅验证 Windows x64 Edge / Chrome；未验证其他平台/架构。

完整解压到固定位置，打开 `edge://extensions` 或 `chrome://extensions`，开启开发人员模式并加载包内 `extension` 文件夹；普通用户无需安装 Node.js、依赖或编译。返回普通网页并刷新。需要同步与自动安装更新时，运行 `sync/start.cmd`。GitHub 的 Source code 附件是源码，不是成品。

## 升级与限制

旧版没有更新程序，需先手动覆盖原加载目录升级到本版，重新加载扩展并重启浏览器一次，以清除旧版标签页专用侧栏状态。不要卸载旧扩展或更换加载目录。同步用户一起更新全部浏览器和服务。

自动安装需要完整包的 `extension` 和 `sync` 两个相邻目录及写权限；仅扩展包只检查和提示下载，仅同步包不自动查找安装目录。服务已运行时不覆盖程序文件。设置 `QIBIAN_AUTO_UPDATE=0` 可关闭启动自动安装。下载使用公开 GitHub 正式版本，需要网络；不使用测试版，不自动降级。

扩展数据仍保存在浏览器扩展存储和 IndexedDB，服务数据在 `%LOCALAPPDATA%\QibianSync`。升级前导出配置并保留原歌曲和文件；JSON 备份不含文件本体。天气、RSS、更新和网站图标读取需要网络，无需 API Key。

浏览器内部页面及扩展商店不能注入网页图标栏。未验证系统权限确认弹窗、组织策略、登录启动注册表操作或全部第三方网络服务。项目启动脚本未签名，项目未指定开源许可证；第三方许可证随包保留。
