# 栖边 1.5.2

栖边是 Edge / Chrome 的自定义侧边栏，把网站、文件、天气、RSS、便笺、时钟和音乐歌单放在手边。本次是仓库的首个 GitHub Release，沿用已有 1.5.x 版本规范，重点补齐普通用户可直接使用的发行包、固定运行时、许可声明和成品验证流程。

## 推荐下载

**qibian-1.5.2-windows-x64.zip（推荐下载）**：包含完整扩展、可选本机同步服务及使用说明。同步服务已内置官方 Node.js 24.22.0，无需安装 Node、npm、pnpm 或编译代码。

GitHub 自动提供的 **Source code (zip/tar.gz)** 是源码，不是可直接运行的安装包。其他系统、ARM64、32 位和其他浏览器未验证，不提供对应服务成品。

## 首次启动

1. 完整解压推荐包到固定文件夹。
2. 在 Edge 打开 `edge://extensions`（Chrome 用 `chrome://extensions`），开启页面中的「开发人员模式」，选择「加载解压缩的扩展」，选中 **extension** 文件夹。这只是浏览器加载本地扩展的开关，不需要开发环境。
3. 返回普通网页刷新，点击右侧「栖」或浏览器工具栏图标打开边栏。
4. 需要跨浏览器同步时，双击 **sync/start.cmd**，保持窗口运行。在各浏览器栖边设置中填入相同配对密钥，先连接主要内容所在浏览器。

## 包含的主要功能

- 新增网站自动读取网址、标题和网站图标，支持手动网址、文字图标和上传图片。
- 网站、文件、天气、RSS、媒体、便笺、时钟卡片，可排列、复制、导入 OneTab / 收藏夹和切换统一配色。
- 44px 图标栏与完整边栏切换，音乐和网站支持图标快捷操作。
- 独立歌单管理、多选歌曲、排序与四种播放顺序，收起侧栏后音乐继续播放。
- 同机 Edge / Chrome 共享卡片、设置、歌单、已导入文件和音乐控制；可从另一浏览器停止或接管播放。断线保存本地待同步修改，重连补发。
- 新增带固定 SHA-256 的官方 Windows x64 运行时打包、许可证与来源文件、校验清单及自动发布流程。
- 修复快速收起再展开时，重复“原生边栏已关闭”状态通知可能取消用户展开的问题；已加入确定性竞态回归。

## 依赖、数据和升级

浏览器本身需已安装。天气连接 Open-Meteo，RSS 和图标读取访问指定网站，需要网络；不需要 API Key。已保存的便笺、卡片、文件和音乐可离线使用。跨浏览器同步依赖本机服务，只监听 `127.0.0.1:17381`，不向云端上传，不扫描浏览器个人资料和未导入文件。

扩展数据在浏览器扩展存储和 IndexedDB；同步服务数据与密钥在 `%LOCALAPPDATA%\QibianSync`，不写入程序目录。JSON 配置备份不包含文件本体，请另存原文件。升级前备份并退出旧服务，保持扩展原有加载目录，覆盖程序后重新加载扩展并刷新网页。不要卸载旧扩展。没有自动更新机制。取消登录启动及删除程序不会自动清理用户数据。

## 验证与限制

本次使用真实 Windows x64 环境、实际分发 ZIP 解压成品及隔离浏览器配置文件验证：资源完整性与无私人路径、51 项单元测试、中文空格目录且无已安装 Node 的 `start.cmd` 启动、二进制文件保存读取、配对密钥与配置重启持久化；真实 Edge / Chrome 中验证图标读取、卡片复制、OneTab/收藏夹导入、配置导出与恢复、配色、105 首歌单及播放顺序、原生边栏与图标模式、跨浏览器文件同步、停止/接管播放和断线重连。发布流程会在上传正式资产前重新执行这些必需检查。

未执行可选 Windows 登录启动项的真实安装/卸载；不验证其他操作系统、其他架构或所有第三方网站。天气与 RSS 的自动化验证使用明确的测试响应，不代表所有真实来源可用。受网站 CSP、X-Frame-Options、网络和权限影响，内嵌或图标抓取可能不可用；可改为新标签页或手动图标。浏览器内部页和扩展商店无法显示网页图标栏。网页媒体控制不覆盖所有播放器，跨浏览器同步只控制栖边音乐。卡片最多 200 张；文件和歌单受存储空间限制。同一字段并发同步按服务接收顺序确定结果。

本项目未上架商店、未配置项目代码签名，启动脚本未签名；随包 Node.js 官方签名已校验为有效（OpenJS Foundation），这不等于本项目通过系统信誉认证。请核对 SHA-256，不要关闭安全防护。项目自身尚未指定开源许可证，见随包 `RIGHTS.md`；Node.js 与 ws 的完整第三方许可证已保留。
