# qibian

## 栖边 · 自定义浏览器侧边栏

**1.6.1** 修复原生侧栏打开后被启动重置关闭的问题，统一为窗口级侧栏；新增版本检查和 Windows 完整包自动更新。仍保留图标栏位置拖动、OneTab 快捷方式与跨浏览器同步。启用同步时，请一起更新所有浏览器与本机服务。

栖边把网站、文件、天气、RSS、便笺、时钟和音乐歌单放在浏览器右侧。支持完整面板与 44px 图标栏、卡片复制与排列、网站标题和图标自动读取、上传自定义图标、预设配色，以及同机 Edge / Chrome 之间的文件与音乐控制同步。

## 从下载到首次使用

1. 把推荐包完整解压到固定位置，保留整个目录。
2. 打开 Edge 的 `edge://extensions`（Chrome 为 `chrome://extensions`），开启该页面的「开发人员模式」，点击「加载解压缩的扩展」，选择包内 **extension** 文件夹。这是浏览器加载本地扩展的开关，不需要开发环境。
3. 刷新普通网页，点击右侧「栖」或浏览器工具栏的栖边图标。向右按钮切回图标栏并释放原生侧栏宽度。
4. 需要跨浏览器同步时，双击 **sync/start.cmd**。在各浏览器栖边设置中填入同一个配对密钥，先连接内容最多的浏览器。无需安装额外运行时。

完整步骤、备份、升级、停止服务与权限限制见 [用户使用说明](docs/USER-GUIDE.md)；可选登录启动见 [同步服务说明](companion/README.md)。扩展设置中还包含离线教程，说明 OneTab/收藏夹导入、歌单管理和图标读取。

## 功能与限制

- 网站新增时读取当前网页网址、标题、图标；粘贴其他网址也能读取。支持文字和上传图片，保留自定义图标。网站禁止内嵌时可使用「在网页中打开」。
- 网站、文件、天气、信息流、媒体、便笺、时钟可排列和复制。卡片总数最多 200。
- OneTab 文本/TXT、收藏夹 HTML 可预览后导入，也可授权读取浏览器收藏夹；重复和危险链接会跳过。
- 歌单支持多选导入、排序、列表循环、单曲循环和随机播放。管理页与小组件共享后台播放器；收起侧栏或关闭音乐页仍可播放，浏览器退出后停止。
- 文件与歌曲保存为本机副本，没有应用层单文件/曲目数量上限，受可用磁盘和浏览器存储能力约束。
- 同步服务只监听 `127.0.0.1:17381`，同步栖边内的卡片、配置、歌单和已导入文件。可从 Edge 停止 Chrome 中的栖边音乐，或切换播放浏览器。断线时排队保存本地修改，共享播放停止；重连后补发修改。
- 不扫描浏览器个人资料、未导入的文件，不同步不同电脑，不控制其他浏览器的网站自身音视频。网页媒体控制也受 iframe、网站播放器及浏览器权限限制。
- 天气连接 Open-Meteo，RSS 连接指定信息源，网站图标直接访问对应网站；这些功能需要网络，无需 API Key。未接入第三方图标代理。离线可使用已保存的卡片、文件和音乐。
- 浏览器内部页面、扩展商店等不能显示网页图标栏；可使用工具栏原生侧栏。某些网站会拒绝内嵌、图标读取或 RSS 请求，界面提供提示和手动入口。

## 保存、备份与更新

扩展使用当前浏览器配置文件中的 `chrome.storage.local` 和 IndexedDB。同步服务使用 `%LOCALAPPDATA%\QibianSync`，不向程序目录写用户数据。JSON 配置导出不包含文件和音乐本体，请另外保存原文件；服务数据可在退出服务后整体备份。

旧版先手动升级一次到 1.6.1：备份并退出旧服务，覆盖程序文件；扩展保持相同加载目录，重新加载并重启浏览器一次。不要卸载旧扩展或更改目录。完整包以后由 `sync/start.cmd` 启动时自动下载和安装新版，成功检查间隔一天；`sync/update.cmd` 可立即更新。安装需要相邻的 `extension`、`sync` 目录与写权限；扩展每 6 小时检查版本，界面均关闭且音乐暂停后自动重新加载，也可手动重新加载或重启浏览器。更新不在使用中关闭侧栏，断网继续使用当前版，程序备份位于服务数据目录的 `updates`。详见[自动更新说明](docs/USER-GUIDE.md)。删除程序或取消登录启动不会自动删除本机数据。

## 发行与许可状态

扩展以解压加载形式提供，未上架浏览器商店；项目启动脚本未做 Authenticode 签名，不声称已通过系统信誉认证。随包官方 Node.js 的签名不等于本项目代码签名。请从本仓库 Releases 下载并核对 SHA-256，不要关闭系统安全防护。

项目自身尚未指定开源许可证，见 [权利说明](docs/RIGHTS.md)，公开源码不表示授予未声明的修改和再分发权利。Node.js、ws 的完整许可证及来源在同步包中保留；扩展未捆绑第三方字体、歌曲或用户文件，图标由项目脚本生成。

## 开发与再次发布

开发构建使用 Node.js **24.22.0**、pnpm **11.25.0** 和锁文件。执行 `pnpm install --frozen-lockfile`，`pnpm test`、`pnpm check`，再执行 `pwsh -File scripts/package.ps1`。构建时从 Node.js 官方下载固定版本的 Windows x64 运行时并校验锁定 SHA-256。这些工具仅供开发者使用，不是普通用户的安装步骤。

[Release 工作流](.github/workflows/release.yml) 支持手动验证和 `vX.Y.Z` 标签发布。普通代码推送不创建 Release。发布前同步 `manifest.json` 与 `package.json` 的版本、更新对应 `releases/vX.Y.Z.md`，推送提交和新标签。流程先完成测试、打包、ZIP 解压验证及浏览器测试，再发布全部资产；已存在的 Release 会拒绝覆盖。预发布标签可在后续明确增加，不对未通过关键验证的成品发布稳定版。

本次验证范围及尚未验证内容见 [1.6.1 发布说明](releases/v1.6.1.md) 与 [验证记录](VALIDATION.md)。测试依赖 Playwright，通过已安装的 Edge / Chrome 运行，不需要本机私人目录；可使用 `PLAYWRIGHT_MODULE`、`QIBIAN_EDGE_PATH` 和 `QIBIAN_CHROME_PATH` 显式指定测试工具位置。
