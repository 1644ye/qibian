# qibian

## 栖边 · 自定义 Edge 侧边栏

1.5.1：新增网站时自动读取当前普通网页的网址、标题和图标，也可粘贴网址自动读取对应信息。保留文字图标和本地上传；上传图片优先，自定义图标不会被自动覆盖。自动图标保存为本地 PNG，可随配置备份和跨浏览器同步；点击「自动读取图标」可替换自定义图标。读取失败仍可手动保存。

一个无远程脚本的 Manifest V3 扩展。网站、文件和日常组件集中在 Edge 侧边栏，配置保存在当前浏览器配置文件内。源码可直接加载；发布包经过合并和压缩，安装时不需要构建工具。

1.5.0 新增同机跨浏览器同步。Edge、Chrome 都安装本扩展，在设置中配对同一个本机服务后，卡片、外观、歌单和已导入文件自动同步；显示当前播放浏览器，可跨浏览器暂停、停止、切歌，或切换播放位置。断线时保存待同步修改，重新连接后补发。不同字段独立合并；同一字段按服务接收顺序更新。

跨浏览器功能需要另外运行 `dist/qibian-sync-1.5.0.zip` 中的 `start.cmd`（需要 Node.js 20+，支持自动查找 Codex 自带运行时）。先连接内容最完整的浏览器，再连接其他浏览器。可选的登录启动脚本与完整步骤见 [本机同步服务说明](companion/README.md)。服务只监听回环地址，配对一次后自动重连；没有云端、账号或跨电脑同步。只同步栖边内已导入的数据，不扫描浏览器个人文件和网站媒体。不启用同步时，原有功能独立运行。

## 安装

1. 在 Edge 地址栏输入 `edge://extensions`，打开「开发人员模式」。
2. 点击「加载解压缩的扩展」，选择此目录（包含 `manifest.json`）。如果使用 ZIP，请先解压。
3. 普通网页右侧自动显示竖向缩略图标栏。点击「栖」展开完整侧栏；音乐图标直接播放/停止，网站图标直接新建标签页打开网址，其他图标直接显示对应组件或文件预览。
4. 固定工具栏中的栖边图标。在正在浏览的网页点击该图标，栖边会直接打开在 Edge 右侧边栏；切换其他网页后仍可使用，不会另开栖边标签页。
5. 更新时将新版文件解压覆盖到原扩展目录，在扩展管理页面点击「重新加载」，然后刷新已经打开的普通网页，使旧图标栏换成新版。1.4.0 新增后台音频与本地存储权限，如 Edge 提示请确认。不要卸载旧扩展，以免丢失本地文件。

1.4.11 在设置顶部加入「使用教程 · 导入网站与管理歌单」，按主题折叠展示 OneTab 文本/TXT 导入、收藏夹读取/HTML 导入、歌单创建与自动保存、歌曲排序和播放顺序、备份迁移及边栏外观操作。侧栏与音乐管理页共用同一份离线教程，继续使用精简构建。

## 使用

- **两种模式**：浏览器启动后普通 HTTP(S) 网页默认显示右侧 44px 竖向图标栏，点击「栖」展开网页内面板，顶部「⇥」收起回图标模式。点击浏览器工具栏中的栖边图标会直接打开 Edge 原生边栏，可伴随不同网页使用。浏览器内部页面、新标签页、扩展商店等页面不允许注入图标栏，使用工具栏打开原生边栏。全屏播放时暂时隐藏网页图标栏。
- **添加内容**：网站、文件、天气、RSS / Atom、媒体、便笺、时钟。卡片右上角 `···` 可修改名称和最小高度，`⧉` 可复制整张卡片（网站图标和便笺也会复制）。文件卡片可共享不可变文件副本，删除其中一张不影响其他副本；更换文件仅影响当前卡片。
- **整理**：点击「整理」，拖动卡片底部的把手排序；也可使用上移、下移按钮，或删除卡片。布局自动保存。
- **网站**：可自定义文字/表情图标，或上传不超过 256 KB 的 PNG/JPEG/WebP/GIF。网址下方「在栖边中打开」内嵌网页，「在网页中打开」新建浏览器标签页。站点的 CSP / X-Frame-Options、登录和第三方 Cookie 策略可能阻止内嵌。扩展不绕过这些限制。
- **OneTab / 收藏夹**：设置 →「OneTab / 收藏夹导入」，粘贴 OneTab 导出文本（每行 `网址 | 标题`），或选择 TXT / 收藏夹 HTML 文件；也可授权直接读取 Edge 收藏夹。先预览，再追加为网站卡片，自动跳过重复和危险网址。收藏夹文件夹和 OneTab 分组按原有顺序展开；最多 200 张卡片，预览会显示无效、重复和超出容量数量。
- **文件**：导入本地文件副本，不设单个文件大小上限，实际容量取决于设备可用空间。图片、文本、音视频可预览，其他格式（包括 PDF / Office）下载后打开。不会读取或跟踪原文件路径。文本最多预览前 300 KB。
- **天气**：输入城市，搜索后选择具体结果。搜索和刷新连接 Open-Meteo。天气是模型数据，打开卡片时超过 10 分钟缓存会更新，也可手动刷新。
- **信息流**：填写 RSS / Atom 的直接地址，点击「授权并刷新」。支持最近 8 条文章，响应最大 2 MB、超时 15 秒，不跟随重定向；遇到重定向请填写最终源地址。部分来源可能拒绝访问。
- **音乐与歌单**：一次可多选音乐，不设曲目数量和单个媒体文件大小上限，总容量取决于设备可用空间。小组件只显示独立的歌单名称与控制按钮，不显示歌曲文件名。点击「管理歌单 ↗」打开独立音乐页，可新建、命名和选择歌单，查看曲目、点击选曲、上移、下移与移除。支持顺序播放、列表循环、单曲循环、随机播放，以及进度和音量调节。管理页和所有小组件共用一个后台播放器，同一时刻播放一个歌单，操作与状态同步；收起侧栏、关闭音乐页后仍继续播放，浏览器退出后停止。视频文件可作为音轨播放，画面请通过文件卡片预览。复制媒体卡片共享只读媒体副本，修改歌单顺序互不影响。
- **播放状态与快捷操作**：完整播放器在未播放或暂停时显示 ▶，播放时显示暂停符号 Ⅱ。小图标模式直接点击音乐图标播放，播放时显示 ■ 并高亮，再次点击停止并将进度归零；不会展开整个栖边。网站图标直接在新标签页打开网址；便笺、天气、信息流与时钟弹出单独组件，文件图标直接显示预览。上述快捷操作同样适用于独立标签页的小图标布局。
- **模式切换与空间释放**：从 Edge 原生侧栏点击顶部向右按钮，会先在当前普通网页右侧准备好 44px 图标栏，再关闭占用宽度的原生侧栏，将空间交还网页。点击「栖」可重新展开完整栖边，音乐继续播放。网页内面板切换到图标模式时保留原页面实例，再次展开恢复原内容。Edge 内部页面和禁止注入的站点不能承载图标栏，切换失败时保留原侧栏并显示原因；完整原生边栏仍可用于这些页面。更新后请确认扩展详情页显示 1.4.10，并刷新已打开网页。
- **网页媒体**：展开「网页媒体控制」后可连接普通网页，控制主页面的 HTML 音视频（播放/暂停、前后 10 秒、静音）；音乐管理页可选择已打开的网页。连接记录在本次浏览器会话内共享。不支持跨域 iframe、封闭 Shadow DOM、部分受保护播放器和浏览器内部页面。
- **外观**：全局采用现代简约布局，新安装默认使用石墨配色，升级保留已有选择。可从「森屿、远海、晚霞、雾紫、石墨」五套预设中选择，每套都有浅色和深色版本；也可切换到「自定义」，分别修改背景、卡片与控件、文字、边框及强调色。当前选择统一应用到所有模块、音乐页、弹窗与图标栏。全局圆角同时作用于卡片与「外观与设置」等弹窗；外层图标栏与网页面板保持固定简约圆角。可调整间距和列数；双列在内容宽度至少 580px 时生效。
- **备份**：导出 JSON 配置，可迁移卡片、便笺和外观。导入替换当前布局；文件和音视频二进制内容不包含在配置中，新设备需要重新选择。卸载扩展会删除本机数据。

## 权限与数据

安装时使用 `sidePanel`、`storage`、`activeTab`、`scripting` 和 HTTP(S) 网站访问权限，用于自动在普通网页注入图标栏、读取指定信息源和用户主动连接的媒体。`offscreen` 用于界面关闭后的后台音频，`unlimitedStorage` 用于本地媒体与大量歌单元数据。图标栏使用隔离的 Shadow DOM，展开页使用扩展 iframe，不读取宿主网页内容。按需申请 `tabs` 以选择网页媒体，按需申请 `bookmarks` 以读取收藏夹。

设置使用 `chrome.storage.local`，文件使用 IndexedDB。无账号、统计、云同步或代理服务器。访问网站会与该网站建立连接，天气搜索会发送输入的城市名称，信息流直接访问指定源。只渲染信息流文本及安全 HTTP(S) 链接，不执行源中的 HTML。未提供发布到 Edge 商店所需的商店页面及商业服务配置；Open-Meteo 商业使用请检查其服务条款。

## 开发与验证

Node.js 20+，运行 `npm test` 和 `npm run check`，无需安装生产依赖。

构建精简发布包：安装 pnpm，执行 `pnpm install --frozen-lockfile` 后运行 `pnpm build`。输出目录为 `dist/qibian-edge-版本号/`，可直接加载到 Edge。PowerShell 7 下运行 `./scripts/package.ps1` 会构建并生成同名 ZIP。esbuild 仅为锁定版本的开发依赖，不随扩展分发；预编译平台包已提供二进制，因此禁用其安装脚本。

`scripts/build.mjs` 合并三个模块入口并提取共享模块，保留内容脚本的独立执行环境；按原顺序合并 CSS，保留 HTML 内容、图标、入口路径和存储格式。只替换 `dist` 下当前版本的生成目录。`dist/build-版本号.json` 记录文件列表和字节数。完整源码、测试、开发依赖和构建统计不进入安装包。

验证压缩版时，在运行浏览器测试前设置 `$env:QIBIAN_EXTENSION_ROOT='C:/apps/work/edge/dist/qibian-edge-1.4.10'`。原生侧栏测试使用 `node tests/display-mode-browser.mjs --return-to-web --with-music --disabled-launch --switch-webpages --blocked-injection --exclusive-surfaces`，通过界面调用打包后的真实入口，不依赖已经合并掉的源码模块。

扩展使用原生 JavaScript ES Modules、CSS、IndexedDB、Edge Side Panel / Offscreen API。也可通过本地 HTTP 服务器预览 `sidepanel.html`；网页预览用 localStorage 保存设置，不具备后台播放器、独立音乐页跳转及扩展的跨域访问和网页控制能力。真实扩展回归使用 `node tests/modern-browser.mjs`（可调整脚本中的 Playwright 路径），已有卡片功能使用 `node tests/revision-browser.mjs`。

安装后建议实际验证：打开侧栏；添加并重排卡片；重开侧栏检查保存；授权天气与 RSS；导入文件并重启浏览器后预览；在含原生 audio/video 的网页上连接媒体；撤销网站权限后检查错误提示。
