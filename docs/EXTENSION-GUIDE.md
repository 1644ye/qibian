# 栖边扩展成品包

本包已构建，包含全部扩展运行资源，不需要 Node.js、npm、开发工具或编译。

1. 完整解压到固定文件夹。
2. Edge 打开 edge://extensions，Chrome 打开 chrome://extensions，开启此页的「开发人员模式」。
3. 选择「加载解压缩的扩展」，选中含 manifest.json 的文件夹。推荐完整包中该文件夹名为 extension。
4. 返回普通网页刷新，点击右侧「栖」展开，或从工具栏图标打开原生侧栏。

更新时保持原文件夹路径，备份配置与原文件后覆盖程序并重新加载，不要卸载扩展。设置与文件在浏览器扩展存储中，不存入本包目录。JSON 配置导出不含音乐与文件本体。

同机跨浏览器同步需要另外启动本机同步服务。完整 Windows x64 包已包含 sync 文件夹，单独下载时选择对应版本的 qibian-sync-版本号-windows-x64-portable.zip。双击 start.cmd，服务自带运行时；在各浏览器栖边设置中填同一密钥。

实际验证为 Windows x64 的 Edge / Chrome。未上架商店，不自动更新，不声明其他平台兼容性。网页图标栏需要网站权限；浏览器内部页或禁止注入的页面可使用原生侧栏。天气、RSS、图标读取需要网络；无网络时仍可使用已保存内容。
