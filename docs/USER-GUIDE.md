# 栖边：下载后使用

## 最短开始步骤

1. 把压缩包完整解压到一个以后不随意移动的位置，例如用户文档中的 `Qibian` 文件夹。不要直接在 ZIP 中运行。
2. 打开 Microsoft Edge 的 `edge://extensions`（Chrome 使用 `chrome://extensions`），开启此页面的「开发人员模式」。这只是允许加载本地扩展，不需要安装开发工具。
3. 点击「加载解压缩的扩展」，选中包内的 **extension** 文件夹（其中有 `manifest.json`）。单独扩展包则选解压后的根目录。
4. 返回普通网页并刷新。右侧会出现竖向图标栏；点击「栖」展开，或固定并点击浏览器工具栏的栖边图标打开原生侧栏。

浏览器本身需已安装。此版本实际验证的平台为 Windows x64、Microsoft Edge 和 Google Chrome；其他操作系统、ARM64、其他浏览器未验证，不提供对应原生服务包。扩展没有上架浏览器商店，也不自动更新。

## 跨浏览器同步（可选）

完整包已包含 **sync** 文件夹，独立同步包也可使用。双击其中的 `start.cmd`，保持服务窗口运行。包内自带官方 Node.js 运行时，无需安装 Node.js、npm 或任何依赖。

在各浏览器安装栖边，在设置 →「跨浏览器同步 · 本机」中填写窗口显示的相同配对密钥。先连接内容最完整的浏览器，再连接其他浏览器。服务默认只监听 `127.0.0.1:17381`，不向云端上传。关闭服务后修改先在本浏览器保存，服务恢复后自动补发；共享播放会停止，恢复后需手动播放。

可同步卡片、设置、便笺、歌单、已导入文件及栖边音乐控制。在一个浏览器播放，可从另一个浏览器暂停、停止、切歌或接管播放。不扫描未导入文件、浏览器个人资料或网站自身播放器，不支持跨电脑同步。首次合并的卡片冲突保留副本；同一字段并发修改按服务接收顺序处理，请避免离线时同时修改同一个歌单。

## 数据、备份和升级

- 扩展卡片和设置保存在当前浏览器配置文件的扩展存储中，文件副本保存在 IndexedDB。包目录不保存这些数据。
- 同步服务数据与密钥保存在 `%LOCALAPPDATA%\QibianSync`，不写入解压目录。退出服务后可复制整个目录备份。
- 设置中的 JSON 导出只包含配置、图标及歌单信息，不含歌曲和其他文件本体，请另行保留原文件。同步服务另存的文件备份不会在删除卡片时自动清理。
- 升级前备份配置和原文件。退出旧同步服务，覆盖其程序文件；扩展仍使用同一个文件夹路径，覆盖程序后在扩展页面点击「重新加载」，再刷新网页。不要卸载旧扩展或改变加载路径，以免扩展身份和数据发生变化。
- 关闭服务窗口即可停止服务。自动启动为可选功能，详见 `sync/README.md`。删除程序之前可运行取消自动启动脚本；用户数据保留在上述位置，不自动删除。

## 联网、权限和限制

天气访问 Open-Meteo，信息流访问你指定的 RSS/Atom，自动网站图标直接访问对应网站；这些功能需要网络，无需 API Key。离线可使用已保存的卡片、便笺、文件和音乐。网站若禁止内嵌、限制图标抓取或拒绝 RSS 请求，会显示提示，可改为打开新标签页或上传图标。

浏览器内部页面、扩展商店等不允许网页图标栏，仍可尝试工具栏原生边栏。需要授予扩展相应网站访问权限。网页媒体控制受浏览器和网站限制，不支持所有播放器。应用没有人为限制歌曲或文件大小，但受磁盘空间和浏览器存储能力约束；卡片总数上限 200。

本项目未配置代码签名证书，扩展为本地解压加载形式，启动脚本没有 Authenticode 签名；随包 Node.js 的签名由 Node.js 官方提供，不等于本项目通过系统信誉认证。请从本仓库 Releases 下载，核对 `SHA256SUMS.txt`；不要关闭系统安全防护。如果组织策略禁止本地扩展或脚本，请联系组织管理员。
